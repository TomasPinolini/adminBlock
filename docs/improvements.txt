    2. Auditoria / Log de Actividad  [COMPLETADO]
       - Registrar quien hizo cada accion (crear, editar, eliminar)
       - Registrar que cambio (campo anterior -> nuevo valor)
       - Tabla activity_logs con userId, action, entity, entityId, changes, timestamp
       - UI para ver historial de actividad por entidad (ActivityModal)
       - Integrado en pedidos: crear, editar, eliminar, duplicar, archivar, pagos

===============================================================================
 MEDIA PRIORIDAD
===============================================================================

    3. Generacion de PDFs  [COMPLETADO]
       - Factura A, B, C, NC, ND, Recibos con jsPDF + AutoTable
       - Reporte mensual PDF (ventas + gastos + balance)
       - Business name/address configurables via env vars

    4. Calendario de Entregas  [COMPLETADO]
       - Vista calendario de pedidos por fecha de entrega (dueDate)
       - Vista mensual (CSS grid) y semanal (lista)
       - Navegacion por mes/semana, boton "Hoy"
       - Color coding por estado (azul/amarillo/verde/rojo)
       - Click en pedido abre modal de edicion
       - Mobile: dots compactos en lugar de pills

    5. Dashboard Mejorado  [COMPLETADO]
       - Graficos de ventas vs gastos por mes (Recharts)
       - Top clientes por facturacion
       - Servicios mas vendidos
       - Comparacion mes actual vs mes anterior
       - KPI cards con porcentaje de cambio

    6. Operaciones en Lote (Bulk Actions)  [COMPLETADO]
       - Seleccionar multiples pedidos -> archivar, cambiar estado, eliminar
       - Boton "Seleccionar" activa modo seleccion con checkboxes
       - "Seleccionar todo" / "Deseleccionar todo"
       - Barra de acciones flotante fija al pie con confirmacion
       - API bulk con query atomica WHERE id IN (...), max 50 IDs
       - Validacion Zod para acciones masivas

    7. Busqueda Global  [COMPLETADO]
       - Command palette con Ctrl+K / Cmd+K (cmdk + shadcn Command)
       - Busqueda client-side desde cache de React Query (sin API extra)
       - Resultados agrupados: Pedidos, Clientes, Acciones rapidas
       - Seleccionar pedido navega a /orders y abre EditOrderModal
       - Seleccionar cliente navega a /clients y abre edicion
       - Acciones rapidas: Nuevo pedido, Nuevo cliente, Ir a cotizador
       - SearchTrigger visible en header desktop

    8. Gastos Recurrentes
       - Marcar gastos como recurrentes (mensual: alquiler, EPE, etc.)
       - Auto-generar gastos recurrentes al inicio de cada mes
       - Editar/cancelar recurrencia

    9. IVA Compras (Credito Fiscal)
       - Agregar campo taxAmount a order_materials / supplier_materials
       - Calcular IVA compras mensual automaticamente
       - Posicion IVA mensual: IVA Ventas - IVA Compras = deuda AFIP
       - Vista en reportes mensuales
